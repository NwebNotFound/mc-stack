# Lokale Compose-Pruefung

`docker-compose.exe` ist das offizielle Standalone-Binary von Docker Compose
v5.6.1, nur innerhalb dieses Projektordners abgelegt (kein PATH-Eintrag).
Quelle: https://github.com/docker/compose/releases/tag/v5.6.1

SHA256, mit der offiziellen `.sha256`-Datei verglichen:
`91b1492f0a923427651e2b955739d732ac36b8191193bf4799e62f3e3525c4cd`

Damit wurde `config --quiet` mit allen Profilen ohne Docker Engine geprueft.
Fuer den Betrieb nach der Docker-Installation `docker compose` verwenden.
